# English PR template

Use English for the title and prose. Lead with the concrete problem and resulting behavior. A small change can use one or two sentences and validation. Keep repository-required sections. Omit optional sections that add no information, and replace writing prompts before publishing.

```markdown
## Summary

Describe the problem and what changes for the user or maintainer. Include a concrete before/after example when useful.

## Validation

- State the checks actually performed and their results. Identify checks not run and material coverage limits.

## Risks or limitations

Include material compatibility concerns, remaining limitations, or follow-up work. Omit when unnecessary.

## Related issues

Link relevant issues when available. Use a closing keyword only when this PR resolves the issue and automatic closure is intended. Omit otherwise.
```

Write a concise title describing the final outcome and follow the repository's title convention. Do not invent issue numbers, test results, or claim verification beyond the evidence.
