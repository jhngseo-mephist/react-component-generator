# 한국어 PR 템플릿

제목과 설명은 한국어로 작성한다. 구체적인 문제와 변경 후 동작을 먼저 쓴다. 작은 변경은 한두 문장과 검증 결과로 충분하며, 저장소 필수 항목은 유지한다. 정보가 없는 선택 항목은 생략하고 게시 전에 안내 문구를 실제 내용으로 교체한다.

```markdown
## 변경 요약

어떤 문제를 해결하고 사용자나 유지관리자에게 어떤 결과가 생기는지 설명한다. 필요하면 변경 전후의 구체적인 예를 포함한다.

## 검증

- 실제 수행한 검증과 결과를 적는다. 미실행 검증과 중요한 검증 범위의 한계를 명시한다.

## 위험 또는 제한사항

호환성 영향, 남은 제약이나 후속 작업 중 중요한 내용만 적는다. 불필요하면 생략한다.

## 관련 이슈

관련 이슈가 있으면 연결한다. 실제 해결한 이슈를 자동 종료하려는 경우에만 종료 키워드를 사용한다. 없으면 생략한다.
```

제목은 최종 변경의 결과가 드러나게 간결하게 쓴다. 대상 저장소의 제목 규칙을 따른다. 이슈 번호·테스트 결과를 만들어 내거나 검증 범위를 과장하지 않는다.
